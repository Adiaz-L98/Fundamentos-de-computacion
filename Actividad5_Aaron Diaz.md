## Algoritmo 

Es un procedimiento que se realiza paso por paso para conseguir un fin
Ejemplo: los buscadores de internet son un sistema que revisa millones de páginas web y muestra cuales son las más útiles. 

## Programa

Es un conjunto de de instrucciones diseñadas para que una computadora realice
tareas especificas.
Ejemplo: un sistema operativo linux es considerado como un programa que se utiliza tanto encomputadoras como servidores.

## Codigo fuente 

Es el conjunto de instrucciones escritas en un lenguaje de programación que dictancómo debe comportarse un programa.
Ejemplo: un lenguaje de programacion como el progrma “hola mundo” de python que se utiliza como un ejemplo introductorio.

## Lenguaje de programacion 

Es un sistema estructurado compuesto por reglas gramaticales,
simbolos y sintaxis que permiten escribir instrucciones comprensibles para una computadora.
Ejemplo: javascript es un lenguaje central de desarrollo web el cual corre navegadores de internet y
servidores.

## Sintaxis 

Son las reglas que rigen la estructura de los simbolos, palabras y la puntuacion que se
encuentran en los lenguajes de programacion.
Ejemplo: python utiliza sangrias (espacios) en lugar de llevar llaves para separar bloques de codigo.

## Variables

Es un espacio en la memoria fisica o virtual de una computadora, donde se almacenan
distintos tipos de datos (valores) durante la ejecucion de un programa.
Ejemplo: se puede declarar variables en JS usando las palabras clave let o cost, la diferencia entre ellas, es el alcance y la reasignación de la variable.

## Constante 

Es un valor fijo que un programa no puede modificar mientras se esta ejecutando. A estos valores fijos tambien se les llama literales.
Ejemplo: hacer un sistema para calcular el precio final de productos en una tienda y necesitamos
aplicar el IVA. Ese valor es fijo 16% o 0.16

## Tipo de dato  

Son las diferentes categorias o clases de informacion que se pueden almacenar y procesar en un programa de computadora.
Ejemplo: Enteros, decimales y cadenas de texto.

## Operador  

Es un simbolo o palabra reservada que presenta una operacion a realizar entre uno o mas operados.
Ejemplo: Los operadores aritmeticos como la +, -, x y /

## Expresion 

Una expresión es una combinación de literales, variables, operadores y funciones que genera un valor al evaluarse.
Ejemplo: Aritmeticas son operaciones con numeros que devuelven un calor numerico, racionales
comparan dos valores y devuelven un valor logico y logicas las cuales ombinan condiciones usando
operadores como a < b && b < c

## Condicional bucle 

Es una estructura de control que repite un bloque de codigo de manera
automatica mientras se cumpla una condicion especifica.
Ejemplo: bucle while (mientras) evalua la condicion de entrar al bloque. Si al iniciar la condicion es
falsa, el codigo no se ejecuta nunca.

## Funcion  

Es un bloque de codigo reutilizable que realize una tarea especifica y puede devolver
un resultado.
Ejemplo: digamos que queremos calcular la raiz cuadrada de un numero tendriamos que escribir.
var raiz = raiz_cuadrada(25)

## Parametro 

Los parámetros son variables que se definen dentro de un método para representar
los datos que ese método necesita. Existen dos tipos: parámetros formales y argumentos reales
(también llamados parámetros reales).
Ejemplo: public class Calculadora {// a y b son los parámetros formales o la plantilla que espera a ser llamada. Public int sumar(int a, int b) {return a + b;}

## Argumento 

Es un valor que se pasa a una función cuando se llama. Estos valores permiten que
la función realice cálculos o procesos personalizados según los datos proporcionados.
Ejemplo: el siguiente ejemplo esta escrito en python. def resta(a, b): return a - b print(resta(10, 5)) #
Salida: 5 print(resta(5, 10)) # Salida: -5 (cambia el orden, cambia el resultado) 

## Retorno 

Son resultados los cuales, opcinalmente, que se pueden devolver desde la funcion.
En muchas ocaciones es mu util devolver este valor para utilizar en otra parte del programa.
Ejemplo: funcion sumar(a, b): resultado = a + b return resultado // Retorna el valor

## Arreglo 

Es una estructura de datos que almacena una coleccion de elementos, los cuales son del
mismo en una secuencia contigua.
Ejemplo: el arreglo unidimensional es simplemente una lista de elementos que estan dispuestos en una fila, es el tipo mas basico y el multidimensional el cual contiene arreglos como elementos.

## Objeto  

Es una unidad de independiente de codigo que agrupa datos (propiedades o atributos) y comportamientos (metodos y funciones) relacionados entre si en una misma estructura.
Ejemplo: python, java y c# estan diseñados para trabajar con objetos. En Python, todo, incluso las cadenas de texto, pueden considerarse un objeto.

## Metodo 

Es un bloque de codigo reutilizable que contiene una serie de instrucciones para realizar una tarea especifica.
Ejemplo: metodo sin retorno (void) recibe un nombre e imprime un saludo en la pantalla, pero no devuelve ningun solo valor.

## Evento  

Son cosas que suceden en el sistema que estás programadas, el sistema produce ("lanza") una señal de algún tipo cuando ocurre un evento, y ofrece un mecanismo para que una acción se ejecute automáticamente cuando ocurre el evento.
Ejemplo: un usuario hace click en un link que lo envia a un formulario o presiona una tecla en el
teclado.

## Compilador  

Es un programa que traduce código fuente escrito en un lenguaje de
programación de alto nivel a código maquina o binario ejecutado por el procesador.
Ejemplos: incluyen programas como Javac (Javacompiler) y Microsoft visual C++.

## Editor de codigo  

Es una aplicación de software echa específicamente para facilitar la
escritura, edición y organización del código fuente. 
Ejemplo: visual code studio y notepad++

## IDE (Entorno de Desarrollo Integrado)  

Es una aplicación de software que centraliza herramientas esenciales para el desarrollo de aplicaciones y programas. 
Ejemplo: AWS (servicios de computacion en la nube), Cloud9, Replit y CodeSandBox.

## Biblioteca  

Es un conjunto de funciones, rutinas y códigos prescritos que ofrecen una interfaz definida para ser reutilizada por otros programas evitando que el desarrollo se tenga que escribir desde cero. 
Ejemplo: algunos programas que caen en esta categoria son Tensor Flow y Numpy.

## Framework  

Un framework en informática es una estructura o marco de trabajo que
proporciona un conjunto de herramientas y patrones prediseñados para facilitar y acelerar el desarrollo de software, evitando escribir código desde cero. 
Ejemplo: el desarrollo de web front y backnet 

## Api  

Una API (Interfaz de Programación de Aplicaciones) es un conjunto de reglas y
protocolos que permite que dos aplicaciones o programas se comuniquen, intercambien
datos y ejecuten funciones entre sí sin necesidad de conocer sus códigos internos.Ejemplo: al iniciar sesión en una red social o al pagar en line

## Repositorio 

Un repositorio en informática es un espacio de almacenamiento centralizado
donde se guardan, organizan, gestionan y difunden datos, archivos o código fuente,
permitiendo el control de versiones y la colaboración eficiente. 
Ejemplo: Git y SVN o docker hub.

## Control de versiones  

 El control de versiones es un sistema que registra los cambios
realizados en archivos (como código fuente o documentos) a lo largo del tiempo,
permitiendo recuperar versiones específicas, revertir errores y colaborar en equipo sin perder información.

## Git 

 Git es un sistema de control de versiones distribuido de código abierto, creado por Linus Torvalds en 2005, diseñado para rastrear cambios en archivos (principalmente código fuente) y facilitar la colaboración en equipos de desarrollo.

## GitHub  

 GitHub es una plataforma de desarrollo colaborativo basada en la nube que
permite a los desarrolladores almacenar, gestionar, compartir y revisar código en
proyectos de software. Utiliza el sistema de control de versiones Git para rastrear cambios históricos en los archivos, facilitando el trabajo simultáneo de múltiples usuarios sin sobrescribir el código original.

## RamaBranch

En el contexto de la programación y el control de versiones, una rama
(branch) es una copia independiente del proyecto que permite realizar cambios,
desarrollar nuevas funcionalidades o corregir errores sin afectar la versión principal y estable del código.

## Commit   

Es una instantánea de los cambios realizados en el código fuente en un
momento específico. Cada commit crea un punto de guardado único (identificado por un
hash) que permite rastrear el historial, colaborar con otros desarrolladores y revertir cambios si es necesario.

## Merger  

En informática, el merge (o fusión) es el proceso de combinar dos o más conjuntos
de datos, archivos o ramas de código en una única entidad coherente. Este concepto es
fundamental en el control de versiones (como Git) y en la gestión de bases de datos.

## Callback 

 Callback (o retrollamada) es una función ejecutable que se pasa como
argumento a otra función, la cual se encarga de invocar la primera en un momento
posterior o cuando se cumple una condición específica.

## Programación sincrona  

Es un modelo de ejecución donde las tareas se procesan de
forma secuencial y estricta, obligando al programa a esperar a que una operación termine completamente antes de iniciar la siguiente.

## Programacion asincronica 

 Es un paradigma de desarrollo que permite a las aplicaciones
realizar múltiples tareas simultáneamente sin bloquear el flujo de ejecución principal.

## JavaScript 

Es un lenguaje de programación interpretado y de alto nivel que constituye,
junto con HTML y CSS, una de las tecnologías centrales del desarrollo web moderno.

## Type scripts  

Es un lenguaje de programación de alto nivel y fuertemente tipado
desarrollado por Microsoft que sirve como superconjunto de JavaScript.
